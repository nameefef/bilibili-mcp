# Contributing

Contributions are welcome when they use capabilities documented by the official Bilibili Open Platform.

Before submitting a change:

1. Link the corresponding official documentation.
2. Keep credentials in environment variables.
3. Add strict Zod input and response validation.
4. Add correct MCP safety annotations.
5. Run `pnpm run check`.

Do not contribute reverse-engineered private endpoints, anti-bot bypasses, account automation, credential extraction, or bulk scraping.
