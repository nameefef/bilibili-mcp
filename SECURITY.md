# Security Policy

Please report security issues privately to the repository owner instead of opening a public issue.

Never include Bilibili `client_id`, `app_secret`, access tokens, refresh tokens, authorization codes, cookies, or raw user data in reports. Revoke and rotate a credential immediately if it may have been exposed.

This project intentionally accepts no arbitrary API host or path. Changes that introduce scraping, undocumented endpoints, authentication bypasses, or secret-bearing MCP parameters will not be accepted.
